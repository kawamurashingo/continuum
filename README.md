# Continuum

> 知識を受け取り、理解し、未来へ渡す。

人類が一度獲得した知識を、次の世代が失うことなく受け取り、さらに積み重ねられる世界を目指します。

このリポジトリは、そのために生涯を通じて考え、試し、記録していく場所です。

## なぜOSSなのか

オープンソースソフトウェア（OSS）は、知識を特定の個人や組織の外へ開き、誰かが学び、利用し、改善できる可能性を作ります。

しかし、ソースコードが公開されているだけでは、知識が未来へ残るとは限りません。動かせないコード、理解されない設計、引き継ぐ人のいないプロジェクトには、失われるものがあります。

私は、OSSを**作る・守る・伝える・引き継ぐ**ことを通じて、その断絶を少しずつ減らしたいと考えています。

## このリポジトリで積み重ねるもの

- **理念** — なぜ取り組むのか、何を目指すのか
- **実践** — OSSの開発、保守、知識継承で試したこと
- **記録** — 成功だけでなく、迷いや失敗、判断の理由
- **仕組み** — 自分以外の人にも継続できる方法

これは完成済みの理論書でも、大きな組織の宣言でもありません。まず一人の開発者の取り組みとして始め、経験に応じて内容を変えていきます。

## 読む

- [VISION.md](VISION.md) — 目指す未来と、その理由
- [ROADMAP.md](ROADMAP.md) — 直近に試すことと、長期的な問い
- [journal/](journal/) — 考えたこと・変わったことの記録

## 最初の約束

1. 残したコードよりも、次の人が理解して使える知識を大切にする。
2. 自分一人に依存しない保守と継承を目指す。
3. 完璧さより、小さくても継続できる実践を選ぶ。
4. 考えが変わったときは、過去を消すのではなく、変化の理由を記録する。

## 完成について

人類の知識を文字どおり永久に保存できるとは限りません。それでも、失われる可能性を減らし、誰かが続きを始められるようにすることはできます。

**自分がいなくなった後も、誰かが知識の続きを書けること。**

それを、この活動の成功の一つと考えます。
