# Continuum

> 作ったものや学んだことが、次の誰かにつながっていくように。

OSSを使ったり作ったりしていると、過去の誰かが残してくれたコードや情報に助けられることがよくあります。

自分が開発や保守を通じて学んだことも、できるだけ記録して、ほかの誰かの役に立つ形にしておきたい。Continuum は、そんな思いから始めた個人的な活動の記録です。

大きな計画があるわけではありません。日々のOSS活動の中で気づいたことを、少しずつ積み重ねていきます。

## 気になっていること

ソースコードが公開されていても、当時の事情や設計の理由が分からなくなっていることがあります。動かし方が分からなかったり、メンテナが不在になったりすることもあります。

そうしたときに、何が残っていれば次の人が取り組みやすいのだろう、と考えています。

OSSを新しく作ることだけでなく、今あるものを保守することや、経験を文章にして残すことにも関心があります。

## ここに残すこと

- **開発** — 作ってみたもの、設計で考えたこと
- **保守** — 既存のOSSを扱う中で気づいたこと
- **記録** — うまくいったこと、迷ったこと、失敗から学んだこと
- **継承** — ほかの人が理解したり引き継いだりしやすくする工夫

## ドキュメント

- [VISION.md](VISION.md) — この活動の背景にある考え
- [ROADMAP.md](ROADMAP.md) — これから試してみたいこと
- [journal/](journal/) — 日々の気づきや記録

## これから

まずは自分が関わっているOSSを題材に、小さく試して、学んだことを書き残していくつもりです。

考え方や取り組み方は、経験とともに変わるかもしれません。それも含めて、長く育てていけるリポジトリにできたらと思っています。
